# OS Challenge — TCP Server in C

**Technical University of Denmark (DTU)**  
University Project | 2026 | In Progress

## Overview

This project focuses on developing a TCP server in C
within a Linux environment as part of a university
systems programming assignment at DTU.

The server communicates with a provided client,
processes computational requests involving SHA-256
hashing, and returns results over a TCP connection.

The project emphasizes systems programming, network
communication, process management, and performance
optimization.

## Technologies

- C
- Linux
- TCP/IP
- POSIX Sockets
- SHA-256
- Vagrant & VirtualBox
- Git

## Implementation

The current implementation includes:

- TCP socket programming using Linux system calls.
- Client-server communication and request handling.
- Process-based concurrency for handling client connections.
- SHA-256 computations and binary data processing.
- Error handling for network operations.
